# h-req

A Claude Code plugin for collaborators who are not engineers. It helps you turn an idea, a problem or a
change you would like into a well-formed request on a project's GitHub repository, and then follow that
request until it is built.

It is part of [h](https://github.com/stiproot), the agentic workflow runtime: h's groomer reads each request
against the same checklist this plugin asks from, and h's agents build the approved ones.

Status: under construction.
